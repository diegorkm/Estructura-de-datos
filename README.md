# Estructura-de-datos

Utilizamos cualquier compilador de C (ejemplo con gcc) para compilar el archivo con nombre ugit
gcc -o ugit ugit.c

Para iniciar el repositorio de Ugit utilizamos:
./ugit init

Para añadir main.c a staging utilizamos:
./ugit add main.c

Para realizar un commit utilizamos:
./ugit commit-m "commit"

Para ver el log utilizamos:
./ugit log

Para ver un commit específico utilizamos:
./ugit checkout <id del commit>
